# 300 days to QA 🐞

Хочу спробувати себе в тестуванні й вирішила не гадати, а щодня робити по маленькому кроку протягом 300 днів. Тут зберігається мій прогрес.

## Що тут відбувається

Для практики я знайшла сайт [the-internet.herokuapp.com](https://the-internet.herokuapp.com): це безкоштовний полігон для автотестів з десятками маленьких сторінок (чекбокси, алерти, дропдауни тощо). Проходжу їх по одній і пишу тести на Playwright + TypeScript.

## Як запустити

```bash
npm install
npx playwright test
```

## Стек

Playwright, TypeScript
